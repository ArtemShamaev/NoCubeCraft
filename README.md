# NoCubeCraft

Песочница-выживание в мире из маленьких блоков (25 см) разных форм: кубов, плит, скосов, внутренних и внешних углов. Блоки покрыты PBR-материалами (камень, кора, доски, трава и другие) с рельефом и фасками на рёбрах. Вблизи видны блоки, а издали холмы выглядят гладкими. Rust, Bevy 0.20, физика avian3d.

В игре есть:
- бесконечный мир с биомами: равнины, леса, тайга, снежные земли, пустыни с кактусами, саванны с акациями, болота; горы, озёра;
- пещеры: извилистые тоннели с входами на поверхности и большие пустоты в глубине, где без факела темно;
- физика: подрубленное дерево падает целиком и роняет соседние, песок и гравий осыпаются, если под ними выкопать;
- клей, скоба и физический активатор: склеенная конструкция становится одним падающим телом;
- руины башен и пирамиды в пустынях, в каждой спрятан тайник с добычей;
- измерение Осколков: летающие острова над пустотой, светящиеся ядра и алтарь Стража;
- лук и стрелы, скелеты-лучники, приручение волков костью;
- цели по ходу игры и финал: победа над Стражем Осколков и титры;
- строительство блоками 1 м, 50 см и 25 см шести форм;
- крафт как в Minecraft: сетка 2×2 в инвентаре и 3×3 на верстаке, книга рецептов, печь с топливом, сундук;
- деревянные, каменные, железные и алмазные инструменты и мечи;
- голод и здоровье;
- днём овцы, коровы, свиньи и куры (в каждом биоме свои), ночью зомби, пауки, скелеты и волки (в тайге и снегах);
- смена дня и ночи с облаками и звёздами;
- несколько миров, творческий режим и консоль с читами.

## Запуск

```sh
cargo run --release
```

Первая сборка идёт долго, потому что компилируется Bevy.

Игра собирается в один файл: все модели, звуки и текстуры вшиты внутрь, рядом ничего класть не нужно. `tools/dist.sh` кладёт в `dist/` файлы `NoCubeCraft.x86_64` (Linux) и `NoCubeCraft.exe` (Windows). Для Windows нужны `rustup target add x86_64-pc-windows-gnu` и пакет `mingw-w64-gcc`; `tools/dist.sh --linux-only` собирает только Linux.

## Управление

| Действие | Клавиша |
| --- | --- |
| Ходить, бежать, прыгать / всплывать | WASD, Shift, Space |
| Копать блок выбранного размера, рубить, бить | Удерживать ЛКМ |
| Строить выбранным материалом, ставить предмет, есть | ПКМ (удерживать — ставить подряд) |
| Размер блока: 1 м → 50 см → 25 см | R |
| Форма: куб, плита, плита сверху, скос, ступени, столб | F |
| Спать в кровати, открыть печь | ПКМ по ней |
| Стрелять из лука | Удерживать ПКМ, отпустить |
| Приручить волка / «сидеть» и «за мной» для пса | ПКМ костью по волку / ПКМ по псу |
| Намазать клей, запустить активатор, пройти через разлом | ПКМ |
| Выбрать слот | 1–9, колесо мыши |
| Инвентарь и крафт | E |
| Консоль | T или / |
| Меню паузы | Esc |
| Отладка (FPS, координаты, биом, треугольники) | F3 |
| Полёт в творческом режиме | Двойной пробел; Ctrl — вниз |

Полупрозрачный призрак показывает, где появится блок. Скосы и ступени поднимаются в ту сторону, куда вы смотрите. Рамка показывает, что будет выкопано. Ступеньки высотой до 50 см персонаж проходит без прыжка.

В инвентаре ЛКМ берёт или кладёт стопку, ПКМ берёт половину или кладёт по одному, Shift+ЛКМ быстро перекладывает (в сундук, печь или между хотбаром и рюкзаком).

## Крафт

Разложите предметы на сетке — справа появится результат, нажмите на него (с Shift — скрафтить сколько получится). В инвентаре сетка 2×2, на верстаке (ПКМ по нему) — 3×3; кирки, топоры, сундук и печь делаются только на верстаке. Форма важна, как в Minecraft: кирка — три материала в верхнем ряду и две палки по центру, меч — два материала над палкой. Книга рецептов справа сама раскладывает ингредиенты (с Shift — на столько штук, на сколько хватит).

Печь (ПКМ по ней): сверху — что плавить, снизу — топливо. Железная руда → слиток, бревно → древесный уголь, сырое мясо → жареное. Песчаник — четыре песка квадратом. Уголь горит на 8 предметов, дерево — на полтора. Сундук хранит 27 стопок, содержимое печи и сундука сохраняется и выпадает при поломке.

Железо добывается каменной киркой и лучше, алмазы (глубже −8 м) — железной и лучше.

## Читы (консоль, T)

| Команда | Что делает |
| --- | --- |
| `help` | Список команд |
| `gamemode creative` / `gamemode survival` | Творческий режим / выживание |
| `give <предмет> [кол-во]` | Выдать предмет, например `give diamond_pickaxe` или `give bricks 500` |
| `items` | Названия всех предметов |
| `time set day` / `night` / `noon` / `midnight` / `0.3` | Время суток |
| `tp <x> <y> <z>`, `tp spawn` | Телепорт |
| `heal`, `feed`, `kill`, `clear` | Здоровье, сытость, смерть, очистка инвентаря |
| `seed` | Сид мира |
| `summon <моб>` | Призвать моба: sheep, cow, pig, chicken, zombie, spider, wolf, skeleton, warden |
| `locate`, `locate altar` | Где ближайшие руины / алтарь в Осколках |

Стрелки вверх и вниз листают историю команд.

## Как выжить

1. Нарубите брёвен, сделайте доски, палки и верстак.
2. На верстаке — деревянная кирка, затем каменная.
3. Печь (8 камня кольцом) плавит железную руду; из слитков — железные инструменты.
4. Ночью приходят зомби и пауки, а в холодных краях — волки. Факелы освещают округу и не дают им появляться рядом.
5. Кровать (шерсть и доски) пропускает ночь и задаёт точку возрождения.
6. Голод растёт со временем. Еда: мясо (лучше жареное) и хлеб из пшеницы, семена находятся в траве.

## Как пройти игру

Текущая цель всегда видна в правом верхнем углу.

1. Алмазы и железо дают физический активатор (4 слитка и алмаз крестом).
2. Разлом (4 алмаза крестом, активатор в центре) ведёт в Осколки: ПКМ по нему. Гравитация там слабее, а упавший в пустоту возвращается домой.
3. Ядра осколка светятся в глубине островов и добываются железной киркой.
4. Тропа из островов ведёт к алтарю. 32 ядра, отданные алтарю (ПКМ), пробуждают Стража Осколков.
5. Победа над Стражем — конец игры и титры. Мир после этого остаётся вашим.

Лук: 3 палки и 3 нити (нить — из шерсти или с пауков). Стрелы: гравий, палка и перо (перья — с куриц).

Один предмет-блок равен одному блоку 25 см. Блок 1 м стоит 64 единицы материала.

## Миры, настройки, сохранения

В главном меню можно создать мир (название, сид, режим), продолжить или удалить его. Удаление требует двух нажатий. В настройках задаются дальность прорисовки, поле зрения, чувствительность мыши, полный экран, вертикальная синхронизация и тени.

Миры сохраняются каждые 30 секунд и при выходе. Лежат они в `~/.local/share/nocubecraft/worlds` (на Windows в `%APPDATA%\nocubecraft\worlds`); переменная `NOCUBECRAFT_DATA` задаёт другую папку. Миры из старой папки `barnocraft` переносятся сами при первом запуске.
